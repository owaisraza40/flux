# IDM behavior reference for this revision

The existing Flux engine was retained. IDM artifacts were used as static behavior references; they are not dependencies, and no IDM code, icons, executables, DLLs or extracted extension source are distributed here. This report separates observed facts from the remaining reconstruction gaps.

## Inputs and method

- Supplied `IDMan.exe`: SHA-256 `e3fc655a335e17a6fdd09a9b315291d0c8863180f0d801e5dd7433c9e56afbd8`, x86 PE, version 6.43.15.2.
- REA 6.7.0 inventoried all 39 supplied `.exe`/`.dll` images using its PE resource parser. IDMan.exe has 436 resource entries. Resource inventory is not decompilation of every DLL.
- REA/Ghidra 12.1.4 recovered IDMan.exe HTTP request-builder and Content-Range parsing routines. The default 330-second import timed out; the completed follow-up used a 1,200-second limit and disabled `WindowsResourceReference`. Resource-reference-derived facts are consequently not established by that Ghidra profile; the separate PE resource inventory remains available.
- The supplied native-host manifests, the previously decompiled `IDMMsgHost.exe` helper and the shipped Chromium extension were also inspected. Complete raw evidence and extracted proprietary files stay outside this public repository.

## Standard fallback retained where proprietary policy is unresolved

For a known length `L` and `N` admissible connections, Flux partitions the initial `[0, L-1]` extent into contiguous inclusive regions, accounts for the remainder, and clamps connection count by the minimum useful part size. A freed worker can split a still-active remaining region only after cancelling and joining its previous writer. Checkpoints record flushed ownership/offset state. These are independently implemented standard techniques already present in Flux, not code copied from decompilation.

The tests verify exact resulting bytes, bounded concurrency, non-overlapping ownership, pause/restart recovery and malformed/changed server responses. They do not establish identical timing, performance, every hidden IDM feature or complete proprietary algorithm equivalence. See [validation](VALIDATION.md) for the executed checks and live-media evidence.
